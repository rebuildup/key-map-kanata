Kanata Space HUB v1

US ANSI + 大西配列。キー名はすべて物理US位置。通常文字の大西配列は変更せず、Spaceと左右Shiftを軸に追加レイヤーだけを重ねる。

Space tap通常のSpace。holdするとHUB。
Space + LShifttap = 英数 / hold = 左記号 + 右テンキー。
Space + RShifttap = かな / hold = 左テンキー + 右記号。
Automation片Shiftをhold中に反対Shiftをtap。次の1キーだけ有効。

空欄 = ベース/下位レイヤーへ透過、または無効

覚える順番

  • 最初は Space + H J K L と、左右Shift tapの英数/かなだけ。
  • 編集は Space+F=Enter、Space+G=Delete、その一段上の R/T がShift版。
  • 数字は「Shiftを押していない側」に同じ 789 / 456 / 123 + 0 の形で出る。
  • 記号は「Shiftを押している側」に ()[] / {}<> / :;"| の3段。
  • Mouseは Space+M で常駐。左手WASD、右手HJKLのどちらでも移動できる。

Automation

Space + 片方のShiftをhold → 反対Shiftをtap → 手を離す → コマンドキー。スクショはすべてClipboardへ。Dynamic Macroはキー入力記録で、Clipboard履歴ではない。

実際のClipboard stackはKanata単体では持たせず、必要になったらユーザーセッション側helperを追加する前提。
